Figure scripts (16 Oct 2026)
These scripts produced Figures 1-5 and S1 of the manuscript draft. They were run in the cloud workspace,
so the paths at the top of figcommon.py (U, ANA, CONF, OUT) point to that workspace. To re-run them on your
computer, set U to "E:/Protein and RNA/" and point ANA/CONF to the matching folders (the intermediate arrays
X_all.npy, out_all.txt, subtype_out.txt etc. come from scripts/exploratory/). Ask Claude to make them
fully portable before code release.
